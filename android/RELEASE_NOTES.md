EZEXAM Android APK สำหรับ Android 7.0 ขึ้นไป

- รวมตัวอ่าน Google Forms และ Python engine ในเครื่อง
- วิเคราะห์คำถามและรูปประกอบด้วย Gemini พร้อมตรวจทานคำตอบ
- แก้คำตอบก่อนส่ง พร้อมขั้นยืนยันการส่ง
- เก็บ Gemini API Key แบบเข้ารหัสด้วย Android Keystore
- ไม่ต้องเชื่อมต่อเว็บ Streamlit แต่การวิเคราะห์และส่งฟอร์มต้องใช้อินเทอร์เน็ต
- ตั้งค่า Gemini API Key ของคุณในแอปเมื่อใช้งานครั้งแรก

ดาวน์โหลด EZEXAM.apk แล้วเปิดบน Android เพื่อ install
รุ่นนี้ลงนามแบบ debug สำหรับติดตั้งโดยตรง การอัปเดตที่ลายเซ็นต่างกันต้องถอนรุ่นเก่าก่อน
ทดสอบ Python core, image codec และการเปิด UI บน emulator ก่อนเผยแพร่
ยังไม่ได้ทดสอบกับฟอร์มจริงของผู้ใช้ และไม่ได้ส่งคำตอบจริงในการทดสอบ
