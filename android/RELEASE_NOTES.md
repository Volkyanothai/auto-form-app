EZEXAM Android 2.0 — หน้าตาและฟังก์ชันเดียวกับเว็บ

- เปิดหน้าเว็บจริงในแอป พร้อมดีไซน์และเอฟเฟกต์เดิม
- เข้าหน้าวางลิงก์ Google Forms ได้ทันที
- ไม่ต้องกรอก API Key ในโทรศัพท์ ใช้ระบบคีย์ที่ตั้งไว้บนเว็บไซต์
- รองรับการเลือกรูปจากเครื่อง หน้าตรวจคำตอบและลิงก์ดูคะแนน
- ต้องเชื่อมต่ออินเทอร์เน็ต และเว็บไซต์ EZEXAM ต้องพร้อมใช้งาน
- APK สำหรับติดตั้งโดยตรงบน Android 7.0 ขึ้นไป

ดาวน์โหลด EZEXAM.apk แล้วเปิดบน Android
หากติดตั้งทับเวอร์ชันเก่าไม่ได้เพราะลายเซ็นต่างกัน ให้ถอนรุ่นเก่าก่อน
