# EZEXAM Android 2.0

แอปเปิดหน้าเว็บ EZEXAM จริงภายใน Android จึงใช้ UI เอฟเฟกต์
และฟังก์ชันเดียวกับเว็บทั้งหมด รวมถึงรูปประกอบ การตรวจทานและการส่งฟอร์ม

เปิดแอป วางลิงก์ Google Forms แล้วกดเริ่มวิเคราะห์ได้ทันที
ไม่ต้องกรอก Gemini API Key ในแอป ระบบใช้คีย์ที่ตั้งไว้ใน Streamlit secrets ของเว็บ
โทรศัพท์และเว็บไซต์ต้องเชื่อมต่ออินเทอร์เน็ต

รองรับ Android 7.0 ขึ้นไป การเลือกรูปใช้ตัวเลือกไฟล์ของ Android
ลิงก์ Google Forms และหน้าคะแนนเปิดในเบราว์เซอร์
เมื่อเชื่อมต่อไม่ได้มีปุ่มลองใหม่และเปิดเว็บในเบราว์เซอร์

## ตั้งค่าที่อยู่เว็บสำหรับผู้ดูแล

ใส่ URL เว็บจริงใน `android/webapp.properties`:

```properties
url=https://ezexam.streamlit.app/
```

ไฟล์นี้ใส่เฉพาะ URL ห้ามใส่ API Key
APK ไม่ได้รวม Gemini key หรือ Python runtime
คีย์เก่าที่รุ่น 1 บันทึกไว้ในเครื่องจะถูกลบเมื่อเปิดรุ่น 2

## สร้าง APK

ใช้ JDK 17, Android SDK 35 และ Gradle 8.11.1:

```sh
cd android
gradle assembleDebug lintDebug
gradle connectedDebugAndroidTest
```

GitHub Actions ทดสอบเว็บและ Android ก่อนเผยแพร่ APK
หากยังไม่ตั้ง URL ระบบจะทดสอบตัวแอปด้วยหน้าเว็บจำลองเท่านั้น และไม่เผยแพร่ APK

ไฟล์สำหรับติดตั้งโดยตรงลงนามด้วย debug certificate
หากอัปเดตทับรุ่นเก่าไม่ได้เพราะลายเซ็นต่างกัน ให้ถอนรุ่นเก่าแล้วติดตั้งใหม่
